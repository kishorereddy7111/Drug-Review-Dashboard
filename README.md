# Drug-Review-Dashboard
1️⃣ Project Title / Headline
Skill Development & Regional Performance Analysis Dashboard using Power BI

2️⃣ Short Description / Purpose
This project analyzes skill development program data to identify regional performance, course popularity, and learner engagement levels.

The dashboard helps stakeholders understand which regions offer the most family-friendly or expert-level skilling programs and how different skill categories perform across regions.

The goal is to convert raw data into actionable business insights using Microsoft Power BI.

3️⃣ Tech Stack
Power BI Desktop – Data visualization & dashboard creation

Power Query – Data cleaning & transformation

DAX (Data Analysis Expressions) – Measures and calculated columns

Microsoft Excel / CSV – Data storage

Data Modeling (Relationships, Star Schema)

4️⃣ Data Source
Skill Development Dataset (Excel / CSV file)

Contains information about:

Region

Course Type

Skill Level (Beginner / Family-friendly / Expert)

Enrollment Count

Completion Rate

Revenue / Funding (if available)

5️⃣ Features & Highlights
🔎 Business Problem
Organizations need to understand:

Which region is performing best in skill development?

Which skill level (Family-friendly, Beginner, Expert) has the highest demand?

Are some regions lacking advanced skilling programs?

Where should investment be increased?

📌 Key Business Questions
Which region offers the most family-friendly skilling programs?

Which region provides the highest number of expert-level programs?

What is the enrollment distribution by region?

Which skill category has the highest completion rate?

Which region generates the highest revenue?

Are there underperforming regions that require strategic improvement?

📊 Dashboard Features
Interactive Region Filter (Slicer)

Skill Level Breakdown (Bar Chart)

Enrollment Trend Analysis (Line Chart)

KPI Cards (Total Enrollments, Completion Rate, Revenue)

Region-wise Performance Comparison

Drill-through capability for detailed insights

📈 Insights Delivered
Identified top-performing regions

Compared beginner vs expert skill demand

Highlighted regions needing expert-level expansion

Provided data-driven recommendations for strategic planning
